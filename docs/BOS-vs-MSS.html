BOS vs MSS

How the IFVG Pro HTF bias reads structure

BOS
Break of Structure
Close beyond a swing with the trend → trend continues
                 BOS
         H1 ─ ─ ─ ┼ ─ ─
        /\        /\
       /  \      /
      /    \    /
     /      \  /
             \/
             L1 ← protected low
bias:  BULLISH ─────────▶ BULLISH
MSS
Market Structure Shift
Close through the protected level → trend reverses
              H2  ← new protected high
             /\
        /\  /  \
       /  \/    \
      /   L1     \
 ─ ─ / ─ ─ ─ ─ ─ ─┼─ ─  protected low
    /              \
                   MSS
bias:  BULLISH ─────────▶ BEARISH

BOS  Uptrend continuing

swing being broken protected low previous protected 
BOS 1 → protected low = L1
BOS 2 → protected low moves up to L2       (each BOS trails it up)

MSS  Uptrend turning down

close below L2  →  just a pullback, bias stays BULLISH
close below L1  →  MSS, bias = BEARISH, protected high = H2
                   (only a close back above H2 flips it bullish again)
