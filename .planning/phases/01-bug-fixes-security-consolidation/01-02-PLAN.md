**Step 1:** Add `is_fvg_singular()` function in Section 7 (before `calculate_grade()`, after the stop loss function that ends at line ~1393). Place it here because it is a grading-related function, not a general utility. Add it with the standard sub-section separator.

Per D-01, implement a dual-check algorithm: proximity check AND overlap check. Both must fail (i.e., another FVG is both too close AND overlapping) for singular to be false.

```pinescript
// ─────────────────────────────────────────────────────────────────────
// Check if an FVG is singular (no same-direction FVG nearby AND overlapping)
// Per strategy: singular FVGs are higher quality than clustered ones
// Both checks must fail for the FVG to be non-singular (per D-01)
// ─────────────────────────────────────────────────────────────────────
is_fvg_singular(FVG source_fvg) =>
    bool singular = true
    int fvg_count = array.size(g_fvg_array)

    if fvg_count > 1 and not na(atr_value)
        for j = 0 to fvg_count - 1
            FVG other = array.get(g_fvg_array, j)

            // Skip self -- compare start_bar AND end_bar to identify same FVG
            if other.start_bar == source_fvg.start_bar and other.end_bar == source_fvg.end_bar
                continue

            // Skip opposite-direction FVGs
            if other.is_bullish != source_fvg.is_bullish
                continue

            // Skip non-active FVGs
            if other.status != "active"
                continue

            // CHECK 1: Proximity -- is another same-direction FVG within 5 bars?
            int bar_distance = math.abs(source_fvg.end_bar - other.end_bar)
            bool too_close = bar_distance <= 5

            // CHECK 2: Overlap -- do zones overlap or nearly overlap?
            // Uses ATR * 0.1 tolerance, consistent with EQH/EQL relative tolerance
            float overlap_tolerance = atr_value * 0.1
            bool zones_overlap = source_fvg.top + overlap_tolerance >= other.bottom and
                                source_fvg.bottom - overlap_tolerance <= other.top

            // Both checks must PASS (be problematic) to mark as non-singular
            if too_close and zones_overlap
                singular := false
                break

    singular
```

**Design rationale:**
- Proximity N=5 bars: FVGs are 3-candle patterns, so 2 consecutive FVGs have minimum 3-bar gap. 5 bars allows a small buffer. Consistent with strategy.md section 7.1 "multiple consecutive gaps."
- Overlap tolerance ATR*0.1: Matches existing `i_relative_tolerance` default (0.10) used for EQH/EQL detection.
- Self-skip uses `start_bar AND end_bar` comparison: The source FVG is still in `g_fvg_array` at inversion time (it gets removed at line ~1636 after grading). Without self-skip, every FVG finds itself and is marked non-singular.
- Only checks "active" status FVGs: Inverted/mitigated FVGs are already removed from `g_fvg_array`, but the status check is defensive.
