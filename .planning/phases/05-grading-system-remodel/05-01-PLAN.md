Function signature:
```
check_delivery_from_fvg(bool ifvg_is_bullish, int lookback) =>
```

Returns `bool` — true if delivery from a prior FVG was detected.

Algorithm (per D-01, D-04, D-11, D-12):

1. Determine search direction: for bullish IFVG, look for BEARISH source FVG (price delivered DOWN from it). For bearish IFVG, look for BULLISH source FVG (price delivered UP from it). So: `bool look_for_bullish = not ifvg_is_bullish`

2. Priority cascade search (per D-11): search `g_htf_fvg_array` first, then `g_htf2_fvg_array`, then `g_fvg_array`. If any array yields a delivery match, return true immediately. Per D-12, all sources scored equally.

3. For each array, iterate in reverse (newest first). For each FVG candidate:
   - Must match direction: `candidate.is_bullish == look_for_bullish`
   - Must be active: `candidate.status == "active"`
   - Must be within lookback window: `(bar_index - candidate.end_bar) <= lookback` AND `candidate.end_bar < bar_index`
   - If candidate passes, run body respect check

4. Body respect check (per D-04): iterate candles from `candidate.end_bar` to current `bar_index`. For each candle at offset `k` (where `k = bar_index - candidate.end_bar` down to 1):
   - For bearish source FVG (look_for_bullish = false): check that no candle body closed ABOVE `candidate.top`. Use `close[k]` to get the close at that offset. If `close[k] > candidate.top`, bodies NOT respected, skip this candidate.
   - For bullish source FVG (look_for_bullish = true): check that no candle body closed BELOW `candidate.bottom`. If `close[k] < candidate.bottom`, bodies NOT respected, skip this candidate.
   - Wicks are allowed to penetrate per D-04 — only close matters.
   - Cap iteration at `math.min(bar_distance, 50)` to prevent deep lookback issues.

5. If body respect check passes for any candidate in any array, set `result := true` and break out.

6. Return result.

- Guard array access with size checks: `if array.size(arr) > 0`

New implementation:

```
assess_momentum(float inv_open, float inv_high, float inv_low, float inv_close) =>
    int result = 0
    candle_body = math.abs(inv_close - inv_open)
    candle_range = inv_high - inv_low
    if candle_range > 0 and not na(atr_value)
        body_ratio = candle_body / candle_range
        bool inv_bullish = inv_close > inv_open
        // Count displacement candles (same-direction, body > 50%) in preceding 5 bars
        int displacement_candles = 0
        float leg_range = 0.0
        int leg_size = 5
        for k = 1 to leg_size
            float cb = math.abs(close[k] - open[k])
            float cr = high[k] - low[k]
            if cr > 0
                float br = cb / cr
                bool same_dir = inv_bullish ? close[k] > open[k] : close[k] < open[k]
                if same_dir and br > 0.5
                    displacement_candles += 1
        if inv_bullish
            leg_range := inv_high - low[leg_size]
        else
            leg_range := high[leg_size] - inv_low
        bool strong_inversion = body_ratio > 0.7 and candle_range > atr_value
        bool strong_displacement = displacement_candles >= 2 and leg_range > atr_value * 1.5
        // D-08 scoring:
        // Score 2: BOTH strong inversion AND strong displacement
        if strong_inversion and strong_displacement
            result := 2
        // Score 1: EITHER strong inversion OR displacement (not both)
        //          OR moderate candle (body > 50% AND range > 0.7x ATR)
        else if strong_inversion or strong_displacement
            result := 1
        else if body_ratio > 0.5 and candle_range > atr_value * 0.7
            result := 1
        // Score 0: weak/choppy (body < 30% OR range < 0.5x ATR)
        else if body_ratio < 0.3 or candle_range < atr_value * 0.5
            result := 0
        // else stays 0 (default)
    result
```

- Score 1 has two paths: XOR of strong signals OR moderate candle metrics
- Score 0 for weak/choppy conditions
- Default is 0 (was "neutral" before)
